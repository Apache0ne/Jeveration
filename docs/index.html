Abstract

System One models such as Jev return decisions through fast, parallel prediction. In this paper, we introduce Jeveration, showing that the same decision paradigm can also generate high-quality images in a single forward pass. Jeveration builds on a frozen vision-language model, repurposing its visual-semantic knowledge for holistic image generation. The key challenge is to maintain global consistency. A single prompt admits many valid images, yet parallel predictions must converge on a coherent whole. We therefore condition all positions on a shared random state to coordinate parallel predictions, so that each draw yields a different but coherent image. Since the model tends to ignore this state under direct image supervision, we first learn a distribution over discrete image codes to guide single-pass generation. Beyond text-to-image generation, we further unify image-to-image generation and dense prediction within the same architecture, so that one checkpoint supports all three tasks, each in one forward pass. Experiments show that Jeveration generates a 512×512 image in 78 ms, up to 122× faster than existing unified models, while maintaining competitive image quality and dense prediction performance.

How it works

Generation is one decision

Autoregressive models generate an image token by token, and diffusion models by iterative denoising. Jeveration removes the sequential sampling. It asks a frozen vision-language model for one typed decision, in which all 128 codes of the image are chosen in parallel.

Parallel choices need a shared random state

One prompt admits many valid images. When every code is chosen on its own, different positions follow different images and the regions do not fit together. Jeveration draws one random state per image and conditions every position on it, so each draw yields a different but coherent image.

Codes sampled independently from the first-phase model do not fit together, while Jeveration produces coherent images.

Learned in two phases

Trained on target images alone, the model ignores the random state. Training therefore has two phases.

  1. Learn the image distribution

    The model first learns to fill in masked image codes. This teaches it how the codes of an image depend on each other.

  2. Learn to decide

    The model then turns random states into whole images in one pass. The first-phase model judges each sample and guides the decisions until the codes fit together.

The first-phase model is used only in training, so inference stays a single forward pass.

One frozen model for every task

The backbone is a frozen Qwen3.5-4B with shared LoRA adapters. Task heads read the decision tokens and return image codes, or segmentation, depth and surface normals for dense prediction.

Quality and latency

Jeveration is the fastest model in the comparison at 77.8 ms and reaches 0.74 GenEval. It is 98× and 122× faster than Janus-Pro-1B and Janus-Pro-7B, and scores 0.11 higher GenEval than four-step Show-o Turbo-512 at the same resolution.

Ablations

The effect of each component

The correction target brings a further gain in image quality, and the two branches of the image head together outperform either branch alone. Training on all tasks costs almost no text-to-image quality.

Correction target

Removing the correction target lowers HPSv2.1 at similar GenEval. This suggests that distribution matching sets the composition, while the correction refines details.

Image-head branches

The image head predicts each code with two branches, one initialised from the tokenizer's codebook and a wider one that learns freely. Together they outperform either branch alone, measured on the first-phase model.
